# Quantization journey

How the INT8 configuration was found, including the dead ends. Model: pi05_libero (PaliGemma
vision tower + 27-layer Gemma LM + action expert, ~3.6B params). Target: Jetson AGX Orin 64GB.

## The funnel

1. **Naive all-INT8 collapses quality.** Weight-only INT8 on every GEMM passed the quick task0
   gate (95-100%) but collapsed long-horizon tasks in the 500-episode sweep (t8 -48pp, t9 -73pp
   vs BF16). The task0-only gate was blind to it.
2. **Only the 500-episode record decides.** Success-rate deltas that look free at 20 episodes
   are coin flips at the 92% policy bar; the numbers in this repo are
   500-episode records only; quick gates decide nothing.
3. **The damage carrier is the encoder MLP.** Funneling per-module closed-loop damage localized
   the sink to gate/up projections in the Gemma encoder; attention and down-proj quantize fine.
4. **K16 channel-split mix fixes gate/up.** Keep the K=16 channels with the largest activation
   outliers in BF16, INT8 the rest (per-layer channel sets generated by [scripts/quant/q2ext_outlier_probe.py](../scripts/quant/q2ext_outlier_probe.py),
   shipped as [scripts/quant/mix_sets_k16.npz](../scripts/quant/mix_sets_k16.npz)). Closed-loop back to BF16-level (92.2-92.4% at 500ep).
5. **GEG8 fuses the mix path.** gate/up+GEGLU epilogue kernel, bit-exact three-gate verified,
   -3.2 ms. The recipe above plus GEG8 is what ships.

## What we measured and closed

| Direction | Verdict | One-line reason |
|---|---|---|
| Custom INT8 TC GEMM kernel (mma.s8) | closed | 0.43x vs CUTLASS; stock INT8 path already 2x BF16 |
| K16 -> K8 tighter mix | closed | no structural latency lever (K-related ops are us-scale) + cliff-flat |
| Vision tower INT8 (any subset) | closed | closed-loop 75% vs 90% same-day; no safe sub-boundary found |
| Dynamic activation INT8 (W8A8) | closed | int8dyn TC path measured 2.73x slower than fp16 GEMM on Orin |
| CUTLASS INT8 plugin into the graph | closed | kernel segment 2.17x faster but e2e +5% (stop-loss rollback) |
| INT4 weights | closed | CUTLASS probe shows headroom (106 TF, 77% peak) but no integration path worth it |

## Acceptance rule

Every performance configuration must pass a closed-loop gate at the 500-episode caliber before it
replaces the production recipe; kernel-level bit-exactness is necessary but not sufficient.
Cos-similarity gates alone missed damage that only showed up in long-horizon closed-loop tasks.
