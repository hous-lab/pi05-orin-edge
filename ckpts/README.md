# ckpts/ — weights and upstream artifacts

Upstream-hosted artifacts are **link-only**: download them yourself, verify the hash, place
them exactly where the pipeline expects. Nothing upstream-hosted is committed to this repo
or rehosted elsewhere. The deploy bundle itself is generated locally by our converter, so
the only network fetches are the two small asset files and the fp32 source weights.

## Pipeline layout

```
ckpts/
├── pi05_libero_base/          # fp32 source (download, 14.47 GB)
│   └── model.safetensors
└── pi05_libero_official/      # bf16 deploy bundle (generated by our converter)
    ├── model.safetensors      # 813 tensors, all BF16, 8.29 GB
    ├── norm_stats.json        # downloaded, 1914 B
    ├── meta.json              # generated by run_pipeline.sh (provenance record)
    └── assets/tokenizer/tokenizer.model   # downloaded, 4.1 MB
```

## Deploy bundle (generated, not downloaded)

`export/tools/convert_official_weights.py` converts the fp32 source into the deploy bundle:
all 813 tensors BF16 (fp32→bf16 round-to-nearest-even), embed_tokens materialized from the
tied lm_head and inserted right after it, metadata dropped. The output is byte-identical to
the bundle used for every result in this repo (verified per-tensor against the production
bundle; output sha256 `41cb8647ac785f4fc4ccf0534479b7c97e3406d6c28e8bfe6536e2bb3b7c9ced`).
